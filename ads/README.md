# /ads

Everything ad-related.

- `copy/` — ad copy drafts and final versions, one file per ad or ad set
- `compliance-checks/` — output of compliance checks (the meta-ads-compliance-checker skill and lance-voice reviews), one file per checked asset
- `test-log.md` — every ad test: hypothesis, status, result, compliance rating. The hypothesis gets written BEFORE the ad runs, not after.

Nothing in here goes live without Marina's sign-off.
