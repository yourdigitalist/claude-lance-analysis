# /positioning

`current.md` is the live positioning: hero angle, pillars, proof points, and the WHY behind each.

`archive/` holds previous versions. Never edit history, only supersede: when positioning changes, copy the old `current.md` into `archive/` with a date prefix and a one-line reason for the change, then update `current.md`. Changes to `current.md` always come with an explicit stated reason.
