# Lance — Marketing Ops Context

This file loads automatically at the start of every Claude Code session in this folder. It's the standing context — see the Job Description and Implementation Options docs (in this folder) for the full picture.

## What Lance is
All-in-one project management and invoicing app for freelancers. Core features: client CRM with Kanban pipeline, project management, time tracking, invoicing, file approvals (clients review/comment via a shareable link, no login required), rich-text notes that convert to tasks. Single-seat product. $29/mo, 15-day free trial. Live at getlance.app.

Target audience: freelance designers, web developers, social media managers first.

## Voice rules (non-negotiable)
- No em dashes
- No "this isn't just X, it's Y" contrastive reframing
- No AI-sounding phrasing or generic SaaS clichés ("everything you need, nothing you don't", "simple, honest pricing")
- Casual, direct, short sentences
- Real proof only — never fabricate stats, user counts, or testimonials. If a number isn't real yet, say so instead of inventing one.

## Current positioning
Hero angle: "Organised freelancers earn more." The approvals feature (client review via no-login link) is the real differentiator and should be foregrounded, not buried in a feature grid.

## Competitive picture (last researched: July 2026 — re-verify periodically, don't treat as fixed)
Do NOT default to "Bonsai vs. HoneyBook vs. Dubsado" as the competitive set without re-checking. Last research found the more common real alternative is a DIY stack (Notion + Trello/Asana + FreshBooks/Wave + spreadsheets), not a named paid competitor. Price band for paid all-in-ones: $20–66/mo, Lance's $29 sits inside it. Full detail in the market analysis section of the JD doc.

## Known compliance risk patterns (Meta ads)
- Specific dollar figures in ad creative/screenshots read as implied earnings claims, even in obvious UI mockups
- Scarcity claims ("only X spots left") are a known rejection trigger — only usable if literally true and enforced
- Vague claims ("organized freelancers earn more") are lower risk than specific ones
- Personal-narrative format (no stats, no claims) has been the safest and most on-brand format so far
